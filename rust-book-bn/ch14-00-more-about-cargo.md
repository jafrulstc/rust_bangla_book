# Cargo এবং Crates.io সম্পর্কে আরও

এতকিছু পর্যন্ত আমরা আমাদের code build, run এবং test করার জন্য Cargo-র সবচেয়ে সাধারণ feature গুলোই ব্যবহার করেছি, কিন্তু এটি আরও অনেক কিছু করতে পারে। এই chapter-এ আমরা এর আরও কিছু advanced feature নিয়ে আলোচনা করব, যাতে তোমাকে দেখানো যায় কীভাবে নিচের কাজ গুলো করতে হয়:

- release profile এর মাধ্যমে তোমার build customize করা।
- [crates.io](https://crates.io/)<!-- ignore -->-তে library publish করা।
- workspace ব্যবহার করে বড় project গুলো organize করা।
- [crates.io](https://crates.io/)<!-- ignore --> থেকে binary install করা।
- custom command ব্যবহার করে Cargo-কে extend করা।

Cargo এই chapter-এ আমরা যা যা cover করছি তার চেয়েও অনেক বেশি কিছু করতে পারে, তাই এর সব feature-এর সম্পূর্ণ বিবরণের জন্য [এর documentation](https://doc.rust-lang.org/cargo/) দেখো।
