# The Rust Programming Language

_লেখক: Steve Klabnik, Carol Nichols, এবং Chris Krycho, Rust Community-র
অবদানে_

এই সংস্করণের লেখায় ধরে নেওয়া হয়েছে যে তুমি Rust 1.98.0 (প্রকাশিত 2026-08-20) বা
তার পরের কোনো সংস্করণ ব্যবহার করছ, এবং সব প্রজেক্টের *Cargo.toml* file-এ
`edition = "2024"` উল্লেখ করে সেগুলোকে Rust 2024 Edition-এর নিয়ম অনুসারে কনফিগার
করেছ। Rust install বা update করার নির্দেশনার জন্য [Chapter 1-এর "Installation"
section][install]<!-- ignore --> দেখো, আর editions সম্পর্কে জানতে
[Appendix E][appendix-e]<!-- ignore --> দেখো।

HTML ফরম্যাট online এখানে পাওয়া যায়:
[https://doc.rust-lang.org/stable/book/](https://doc.rust-lang.org/stable/book/)
এবং `rustup` দিয়ে করা Rust installation-এর সাথে offline-এও পাওয়া যায়; খুলতে
`rustup doc --book` চালাও।

বিভিন্ন community [translations]ও পাওয়া যায়।

এই বইটি [No Starch Press থেকে paperback ও ebook ফরম্যাটে][nsprust] পাওয়া যায়।
