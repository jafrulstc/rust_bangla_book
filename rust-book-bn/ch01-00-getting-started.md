# শুরু করা

তোমার Rust যাত্রা শুরু করা যাক! শেখার মতো অনেক কিছু আছে, কিন্তু প্রতিটা যাত্রাই কোথাও না কোথাও থেকে শুরু হয়। এই chapter-এ আমরা আলোচনা করবো:

- Linux, macOS এবং Windows-এ Rust install করা
- এমন একটা program লেখা যেটা `Hello, world!` print করে
- `cargo` ব্যবহার করা — Rust-এর package manager এবং build system
